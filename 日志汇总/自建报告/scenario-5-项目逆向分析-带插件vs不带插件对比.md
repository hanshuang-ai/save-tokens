## 三、关键发现

### 1. 速度
- 总时长：19分41秒 → 6分25秒（-67.4%）
- API 请求次数：56 → 15（-73.2%）
- 最长单次调用：2分15秒 → 2分5秒（-7.7%）

### 2. 成本（关键：区分口径）
- 新增输入 tokens（真正的新 token）：278,834 → 128,567（-53.9%）
- 缓存读取 tokens（缓存命中，成本≈免费）：2,117,632 → 1,097,728（-48.2%）
- 实际总输入（新增+缓存读取，即模型处理的上下文量）：2,396,466 → 1,226,295（-48.8%）
- 输出 tokens：76,172 → 26,775（-64.8%）
- 缓存命中率：88.4% → 89.5%

### 3. 工具链
- 不带插件工具调用 103 次，带插件 24 次
- 插件工具（ctx_*）调用：不带插件 0 次，带插件 4 次

## 四、结论

- 速度：更快（-67.4%）
- 新增输入成本：减少（-53.9%）
- 实际总输入（含缓存）：-48.8%
- 插件工具使用：4 次 ctx_* 调用
