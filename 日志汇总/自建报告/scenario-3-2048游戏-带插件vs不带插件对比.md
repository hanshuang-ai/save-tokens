## 三、关键发现

### 1. 速度
- 总时长：8分8秒 → 7分7秒（-12.5%）
- API 请求次数：19 → 22（+15.8%）
- 最长单次调用：2分48秒 → 1分28秒（-47.6%）

### 2. 成本（关键：区分口径）
- 新增输入 tokens（真正的新 token）：71,833 → 96,205（+33.9%）
- 缓存读取 tokens（缓存命中，成本≈免费）：823,296 → 1,196,032（+45.3%）
- 实际总输入（新增+缓存读取，即模型处理的上下文量）：895,129 → 1,292,237（+44.4%）
- 输出 tokens：32,909 → 29,597（-10.1%）
- 缓存命中率：92.0% → 92.6%

### 3. 工具链
- 不带插件工具调用 18 次，带插件 21 次
- 插件工具（ctx_*）调用：不带插件 0 次，带插件 3 次

## 四、结论

- 速度：更快（-12.5%）
- 新增输入成本：增加（+33.9%）
- 实际总输入（含缓存）：+44.4%
- 插件工具使用：3 次 ctx_* 调用
