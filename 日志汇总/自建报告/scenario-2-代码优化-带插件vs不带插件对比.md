## 三、关键发现

### 1. 速度
- 总时长：10分23秒 → 9分45秒（-6.1%）
- API 请求次数：47 → 28（-40.4%）
- 最长单次调用：1分16秒 → 1分35秒（+24.8%）

### 2. 成本（关键：区分口径）
- 新增输入 tokens（真正的新 token）：110,243 → 134,397（+21.9%）
- 缓存读取 tokens（缓存命中，成本≈免费）：2,784,256 → 1,951,744（-29.9%）
- 实际总输入（新增+缓存读取，即模型处理的上下文量）：2,894,499 → 2,086,141（-27.9%）
- 输出 tokens：38,443 → 37,826（-1.6%）
- 缓存命中率：96.2% → 93.6%

### 3. 工具链
- 不带插件工具调用 56 次，带插件 42 次
- 插件工具（ctx_*）调用：不带插件 0 次，带插件 2 次

## 四、结论

- 速度：更快（-6.1%）
- 新增输入成本：增加（+21.9%）
- 实际总输入（含缓存）：-27.9%
- 插件工具使用：2 次 ctx_* 调用
