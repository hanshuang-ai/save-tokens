## 三、关键发现

### 1. 速度
- 总时长：15分59秒 → 16分3秒（+0.4%）
- API 请求次数：53 → 47（-11.3%）
- 最长单次调用：2分15秒 → 1分27秒（-35.7%）

### 2. 成本（关键：区分口径）
- 新增输入 tokens（真正的新 token）：367,662 → 639,182（+73.9%）
- 缓存读取 tokens（缓存命中，成本≈免费）：4,213,760 → 3,881,984（-7.9%）
- 实际总输入（新增+缓存读取，即模型处理的上下文量）：4,581,422 → 4,521,166（-1.3%）
- 输出 tokens：56,836 → 57,982（+2.0%）
- 缓存命中率：92.0% → 85.9%

### 3. 工具链
- 不带插件工具调用 73 次，带插件 48 次
- 插件工具（ctx_*）调用：不带插件 0 次，带插件 36 次

## 四、结论

- 速度：更慢（+0.4%）
- 新增输入成本：增加（+73.9%）
- 实际总输入（含缓存）：-1.3%
- 插件工具使用：36 次 ctx_* 调用
