## 三、关键发现

### 1. 速度
- 总时长：21分11秒 → 5分36秒（-73.5%）
- API 请求次数：119 → 26（-78.2%）
- 最长单次调用：47.9秒 → 59.9秒（+25.1%）

### 2. 成本（关键：区分口径）
- 新增输入 tokens（真正的新 token）：461,129 → 163,211（-64.6%）
- 缓存读取 tokens（缓存命中，成本≈免费）：5,921,152 → 2,035,712（-65.6%）
- 实际总输入（新增+缓存读取，即模型处理的上下文量）：6,382,281 → 2,198,923（-65.5%）
- 输出 tokens：57,339 → 16,852（-70.6%）
- 缓存命中率：92.8% → 92.6%

### 3. 工具链
- 不带插件工具调用 191 次，带插件 40 次
- 插件工具（ctx_*）调用：不带插件 0 次，带插件 8 次

## 四、结论

- 速度：更快（-73.5%）
- 新增输入成本：减少（-64.6%）
- 实际总输入（含缓存）：-65.5%
- 插件工具使用：8 次 ctx_* 调用
