结论摘要

  • 场景1：日志分析：有插件 Token -41.3%，耗时 -63.2%，缓存命中率 +7.2pp。有插件显著更优
  • 场景2：代码优化：有插件 Token +46.6%，耗时 +60.2%，缓存命中率 +1.7pp。无插件更优（注意：两次运行任务量不同，非直接可比）
  • 场景3：2048游戏：有插件 Token +312.0%，耗时 +165.2%，缓存命中率 +9.1pp。无插件更优（注意：两次运行任务量不同，非直接可比）
  • 场景4：书籍分析：有插件 Token +56.3%，耗时 +37.1%，缓存命中率 +6.9pp。无插件更优（注意：两次运行任务量不同，非直接可比）
  • 场景5：项目逆向分析：有插件 Token +78.7%，耗时 +175.0%，缓存命中率 +1.0pp。无插件更优（注意：两次运行任务量不同，非直接可比）

⚠ 注意：场景 2-5 中，有插件和无插件的运行轮数不同，说明两次独立运行的任务执行路径不同，对比数据仅反映两次实际运行的差异，不能简单归因于插件效果。场景 1 的两次运行任务量接近，更具参考价值。
