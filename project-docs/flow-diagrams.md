# 智慧加油小程序 - 业务流程图

> 使用 Mermaid 语法绘制 | 生成日期: 2026-08-20

---

## 1. 用户加油完整流程

```mermaid
flowchart TD
    A[打开智慧加油小程序] --> B{是否已登录}
    B -->|否| C[触发登录流程]
    C --> D[微信授权登录]
    D --> E[获取手机号]
    E --> F[登录成功]
    B -->|是| F
    F --> G[获取GPS定位]
    G --> H{定位成功?}
    H -->|否| I[显示定位失败页面]
    I --> J[用户点击重试]
    J --> G
    H -->|是| K[加载加油站列表]
    K --> L[展示首页-加油站列表]
    L --> M{用户操作}
    M -->|筛选品牌/油号| N[应用筛选条件]
    N --> K
    M -->|切换排序| O[切换距离/价格排序]
    O --> K
    M -->|点击Banner| P[跳转运营活动页]
    P --> Q{活动类型}
    Q -->|推荐规则| R[跳转油站详情]
    Q -->|加油返现| S[跳转返现页面]
    Q -->|视频/图片| T[展示内容]
    M -->|点击油站卡片| U[进入油站详情页]
    U --> V[加载油站详情 + 服务商列表]
    V --> W[展示油站信息]
    W --> X[选择油号]
    X --> Y[选择油枪]
    Y --> Z[选择服务商]
    Z --> AA[输入加油金额]
    AA --> AB[选择优惠券-可选]
    AB --> AC[提交订单]
    AC --> AD[进入订单确认页]
    AD --> AE{选择支付方式}
    AE -->|免密支付| AF[自动扣款]
    AE -->|微信支付| AG[生成支付二维码]
    AE -->|支付宝支付| AH[生成支付二维码]
    AF --> AI[轮询订单状态]
    AG --> AI
    AH --> AI
    AI --> AJ{支付结果}
    AJ -->|成功| AK[展示支付成功]
    AK --> AL[倒计时返回首页]
    AJ -->|失败| AM[展示支付失败]
    AM --> AN[重新下单 / 返回首页]
    AJ -->|超时| AO[提示支付超时]
    AO --> AN
```

## 2. 订单创建流程

```mermaid
flowchart TD
    A[用户在详情页点击提交] --> B{表单校验}
    B -->|油号未选| C[提示选择油号]
    B -->|油枪未选| D[提示选择油枪]
    B -->|金额未填| E[提示输入金额]
    B -->|服务商未选| F[提示选择服务商]
    B -->|校验通过| G[构建订单参数]
    G --> H[调用下单接口 createOrder]
    H --> I{接口返回}
    I -->|成功 code=0000| J[解析订单数据]
    J --> K[构建订单JSON]
    K --> L[编码订单数据]
    L --> M[NavigateTo 订单确认页]
    I -->|失败| N[展示错误提示]
    N --> O[用户重试]
    O --> H
```

## 3. 支付流程

```mermaid
flowchart TD
    A[进入订单确认页] --> B[解析订单JSON数据]
    B --> C[展示订单详情]
    C --> D[展示支付方式]
    D --> E{用户选择支付方式}
    E -->|微信支付| F{是否开通免密支付}
    E -->|支付宝支付| G{是否开通免密支付}
    F -->|是| H[免密支付-调用paySubmit]
    F -->|否| I[展示微信支付二维码]
    G -->|是| H
    G -->|否| J[展示支付宝支付二维码]
    H --> K[启动轮询 orderStatus]
    I --> K
    J --> K
    K --> L[每3秒查询一次]
    L --> M{订单状态}
    M -->|status=1 支付成功| N[停止轮询]
    N --> O[展示支付成功页面]
    O --> P[5秒倒计时]
    P --> Q[返回首页]
    M -->|status=0 待支付| R[继续轮询]
    R --> L
    M -->|status=4 支付失败| S[停止轮询]
    S --> T[展示支付失败页面]
    T --> U{用户操作}
    U -->|重新下单| V[返回详情页重新下单]
    U -->|返回首页| Q
    M -->|轮询超时| W[停止轮询]
    W --> X[提示支付超时]
    X --> U
```

## 4. 用户登录/注册流程

```mermaid
flowchart TD
    A[页面加载] --> B{检查本地Token}
    B -->|Token存在且有效| C[直接进入页面]
    B -->|Token不存在/已过期| D[触发登录流程]
    D --> E{运行环境}
    E -->|dsBridge 车机端| F[使用dsBridge登录]
    E -->|LA 轻应用端| G[使用LA登录]
    F --> H[调用微信登录 wx.login]
    G --> H
    H --> I[获取微信code]
    I --> J[调用服务端登录接口]
    J --> K{登录结果}
    K -->|成功| L[保存Token/用户信息]
    L --> M{是否已同意用户协议}
    M -->|否| N[展示用户服务授权协议]
    N --> O[用户点击同意]
    O --> P[保存协议同意状态]
    P --> C
    M -->|是| C
    K -->|失败| Q[展示登录失败提示]
    Q --> R[用户重试]
    R --> H
    K -->|需要绑定手机号| S[发送短信验证码]
    S --> T[用户输入验证码]
    T --> U[调用绑定手机号接口]
    U --> L
```

## 8. 异常处理流程

```mermaid
flowchart TD
    A[页面运行中] --> B{监听网络状态}
    B -->|网络断开 offline| C[显示断网组件 wt-load-error]
    C --> D[阻止所有API请求]
    D --> E{网络恢复}
    E -->|online 事件| F[隐藏断网组件]
    F --> G[重新加载数据]
    B -->|接口超时| H[设置 timeOut=true]
    H --> I[显示超时组件 wt-network-error]
    I --> J[用户点击重试]
    J --> G
    B -->|定位失败| K[设置 getlocationerror=true]
    K --> L[显示定位失败组件]
    L --> M[用户点击重试]
    M --> N[重新获取定位]
    B -->|数据为空| O[展示空状态占位]
    O --> P[提示'暂无数据']
    B -->|登录过期| Q[清除本地Token]
    Q --> R[触发重新登录]
```

## 10. 支付状态机

```mermaid
stateDiagram-v2
    [*] --> 待支付: 创建订单
    待支付 --> 支付中: 提交支付
    支付中 --> 支付成功: 扣款成功
    支付中 --> 支付失败: 扣款失败
    支付中 --> 待支付: 支付超时
    支付成功 --> 已退款: 申请退款
    支付成功 --> [*]: 完成
    支付失败 --> 待支付: 重新下单
    已退款 --> [*]: 完成
    待支付 --> 已取消: 取消订单
    已取消 --> [*]: 完成
```
