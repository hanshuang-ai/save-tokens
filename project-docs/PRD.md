## 1. 项目概述

### 1.1 产品定位

智慧加油是一款基于微信小程序的汽车加油服务平台，集成于 TINNOVE 车联网生态系统（车机端 dsBridge 和手机端轻应用 la 双环境运行）。用户通过 GPS 定位搜索周边加油站，支持在线选择油号、选择服务商、下单支付，享受加油返现等优惠。

### 1.2 技术架构

| 维度 | 详情 |
|------|------|
| 框架 | Taro 3.3.3 + Vue 2.x |
| 构建目标 | 微信小程序 (weapp) + H5 轻应用 |
| UI 组件库 | WT-UI（自研组件库） |
| 小程序 AppID | wxfdadb88678cd95a2 |
| 业务 AppID | iyvt7pn3u8php1sz |
| API 基础地址 | https://api.auto-pai.com (生产) / https://api.auto-pai.cn (测试) |
| 埋点系统 | DAQ (https://daq.api.auto-pai.com) |
| 运行环境 | dsBridge（车机端）/ la（轻应用端） |

### 1.3 目标用户

- **主要用户**: TINNOVE 车机系统的车主用户
- **次要用户**: 手机端微信小程序用户
- **使用场景**:
  - 车辆行驶中需要加油，通过车机屏幕搜索周边加油站
  - 用户在家/办公室提前规划加油路线
  - 加油后查看订单、领取返现、开具发票

## 5. 页面交互说明

### 5.1 页面间跳转关系

```
首页(index1) ──点击卡片──> 详情页(detail) ──提交订单──> 订单确认页(order)
    │                          │                        │
    │                          │                        ├──支付成功──> 个人中心(ucenter)
    │                          │                        │
    │                          │                        └──支付失败──> 重新下单
    │                          │
    ├──点击Banner──> Banner详情页(bannerDetail)
    │                    │
    │                    ├──推荐规则──> 详情页(detail)
    │                    ├──加油返现──> 返现页(oilCashback)
    │                    ├──视频/图片──> 展示页
    │                    └──优惠券──> 个人中心(ucenter)
    │
    └──TabBar──> 个人中心(ucenter)
                     │
                     ├──订单列表──> 订单详情
                     ├──收藏列表──> 详情页(detail)
                     ├──偏好设置──> 首页(index1) [刷新]
                     └──设置──> 用户协议/客服电话
```

### 5.2 首页交互逻辑

1. **页面加载**:
   - 检查用户登录状态，未登录则触发登录流程
   - 获取用户 GPS 定位
   - 获取用户偏好设置（默认油号、排序方式）
   - 请求加油站列表 API
   - 获取会员信息（返现相关）
   - 加载运营位 Banner

2. **筛选交互**:
   - 点击品牌筛选按钮，展开品牌选项（所有/品牌优选/壳牌/其他）
   - 点击油号筛选按钮，展开油号选项
   - 选择后自动刷新列表

3. **排序交互**:
   - 点击排序按钮切换「距离优先」/「价格优先」
   - 切换后自动刷新列表

4. **列表滚动**:
   - 下拉触发刷新，pageNo 重置为 1
   - 滚动到底部触发加载更多，pageNo + 1

5. **异常处理**:
   - 定位失败 → 显示定位失败组件，提供重试按钮
   - 网络断开 → 显示断网组件，监听网络恢复
   - 接口超时 → 显示超时组件，提供重试按钮

### 5.3 详情页交互逻辑

1. **页面加载**:
   - 接收首页传递的油站参数（wtStationId, oilNo, 经纬度等）
   - 并发请求油站详情和服务商列表两个接口
   - 两个接口均返回后才渲染页面内容

2. **油号/油枪选择**:
   - 展示可选油号列表，点击切换
   - 切换油号后重新获取服务商列表和价格

3. **服务商选择**:
   - 展示服务商列表，含优惠信息
   - 点击服务商展开/收起
   - 选择服务商后更新价格计算

4. **金额输入**:
   - 支持固定金额快捷选择
   - 支持自定义金额输入
   - 实时计算优惠后金额

5. **提交订单**:
   - 校验必填项（油号、油枪、金额、服务商）
   - 调用下单接口
   - 跳转订单确认页，传递订单信息

6. **导航**:
   - 点击导航按钮跳转腾讯地图
   - 点击电话按钮拨打油站电话

### 5.4 订单确认页交互逻辑

1. **页面加载**:
   - 接收详情页传递的订单 JSON 数据
   - 解析展示订单详情（油站、油号、金额、优惠等）

2. **支付流程**:
   - 展示可用支付方式
   - 免密支付：直接调用支付接口
   - 普通支付：生成支付二维码
   - 启动轮询查询订单支付状态（3秒间隔）

3. **支付结果**:
   - 成功：展示成功图标，5 秒倒计时返回首页
   - 失败：展示失败图标，提供重新下单按钮
   - 处理中：展示加载动画

4. **异常处理**:
   - 支付超时：停止轮询，提示用户
   - 网络断开：展示断网组件

### 5.5 个人中心交互逻辑

1. **页面加载**:
   - 检查登录状态，未登录触发登录
   - 加载用户信息
   - 加载订单列表（默认首页）
   - 加载收藏列表
   - 加载优惠券列表
   - 加载偏好设置
   - 加载免密支付状态

2. **Tab 切换**:
   - 我的订单（默认）
   - 收藏油站
   - 优惠券
   - 设置

3. **订单列表**:
   - 支持上拉加载更多
   - 展示订单状态标签（支付成功/退款失败等）
   - 展示开票标识

4. **偏好设置**:
   - 默认油号选择
   - 排序方式选择（距离优先/价格优先）
   - 保存后同步到首页

5. **免密支付**:
   - 展示微信/支付宝免密支付开通状态
   - 支持开通/关闭操作

### 5.6 异常处理流程

所有页面统一处理以下异常：

| 异常类型 | 处理方式 | 组件 |
|----------|----------|------|
| 网络断开 | 监听 online/offline 事件，显示断网提示 | wt-load-error |
| 接口超时 | 设置超时标志，显示超时提示 + 重试按钮 | wt-network-error |
| 定位失败 | 显示定位失败提示 + 重试按钮 | wt-getlocation-error |
| 数据为空 | 展示空状态占位图 + 文案 | 各页面内联 |
| 登录过期 | 触发重新登录流程 | WtLogin |
| 支付失败 | 展示失败状态 + 重新下单入口 | 订单页内联 |
